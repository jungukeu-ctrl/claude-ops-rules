# Notion HISTORY DB 정의

## DB

- 위치: 프로젝트 Notion 페이지 아래의 인라인 데이터베이스
- 제목: HISTORY — {프로젝트명}

## 속성

속성 이름과 선택지는 아래 표 그대로 사용한다. 조회와 필터가 이 이름에 의존한다.

| 속성명 | 유형 | 값 |
|--------|------|----|
| 제목 | title | 한 줄 요약 |
| 날짜 | date | 결정이나 사건이 발생한 날 |
| 유형 | select | 의사결정 / 전략 변경 / 외부 충격 / 미결 생성 / 미결 해소 / PR 병합 |
| 상태 | select | ✅ 완료 / 🔔 보류 / 🔄 진행중 |

## 항목 본문 형식

    맥락: 왜 이 결정이 필요했는가
    결정: 무엇을 선택했는가
    이유: 왜 이 선택인가 (탈락 대안 포함)
    영향: 어떤 변화가 생기는가
    관련: [Notion 링크] [GitHub PR #번호]

## 조회 예

- 미결: 상태 = 🔔 보류
- 최근: 날짜 내림차순 5건
